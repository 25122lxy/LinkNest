# LinkNest

极简个人书签管理工具

---

## 📋 项目概述

LinkNest 是一个极简的个人书签管理工具，帮助用户管理和快速搜索网址收藏。

---

## ✨ 基本功能

### 核心功能
- 书签展示（列表形式，显示标题、URL、标签）
- 网站 favicon 自动获取
- 关键词搜索（实时过滤）
- 标签筛选（多标签组合，点击跳转新标签页）
- 点击跳转（新标签页打开）
- 响应式布局（移动端优化）
- 按 `/` 快速聚焦搜索框
- 标签收起/展开（默认显示7个）
- 复制链接按钮（点击复制 + Toast 提示）

### 状态管理
- 加载中状态
- 错误提示 + 重试
- 书签数量统计

### 数据存储
- 纯静态 JSON 文件驱动
- 数据文件：`public/data.json`
